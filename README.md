Employee Attrition Analysis and Prediction

Project Overview
This project focuses on analysing employee attrition to understand workforce turnover patterns and identify factors associated with employees leaving an organisation.

Dataset
- 1,500 synthetic employee records.
- Six MySQL tables:
  - Employees
  - Departments
  - Salary
  - Attendance
  - Performance
  - Experience

Technologies Used
- MySQL
- SQL

SQL Work Completed
- Database creation and data import
- Data verification
- Basic SQL queries
- Aggregate functions
- Joins
- Department-wise and job-role-wise attrition analysis
- CASE WHEN statements
- Subqueries
- Common Table Expressions (CTEs)

Key Findings
- Total employees: 1,500
- Employees who left: 239
- Overall attrition rate: 15.93%
- IT department had the highest department-wise attrition rate: 18.72%.

Project Status
SQL analysis completed. Python data cleaning, exploratory data analysis, machine learning and Power BI dashboard development are planned next.
